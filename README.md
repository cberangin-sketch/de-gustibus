# De gustibus

Première maquette fonctionnelle du site.

Architecture proposée : **Jekyll + GitHub Pages + Pages CMS**. Le site reste léger et le contenu peut être administré depuis une interface graphique sans écrire de code.

Champs prévus pour un article : titre, date, rubrique, mots-clés, image de couverture et texte riche.

Rubriques : Jeu vidéo, Films et Séries, Littérature, Divers.

La recherche parcourt titres, rubriques, extraits et mots-clés.

Le nom de domaine `degustibus.fr` reste à enregistrer/configurer après vérification chez un registrar : une recherche web générale ne permet pas de garantir sa disponibilité en temps réel.
